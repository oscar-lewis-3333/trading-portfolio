# Rebound layer

Just after a recession, markets often recover sharply as investor confidence increases, and riskier assets tend to be the biggest beneficiaries of this effect. This basket is chosen for such recovery periods, where it is held for a fixed period following the defensive-exit trigger going off, before re-entering the standard core/sleeves/overlay configuration.

## Results

February 2001 to September 2026, from £10,000, after modelled costs:

| | CAGR | Sharpe | max drawdown | £10,000 becomes |
|---|---|---|---|---|
| core + defensive | 10.8% | 0.85 | −16.0% | £138,200 |
| core + defensive + rebound | 13.3% | 0.92 | −19.8% | £247,400 |

The deeper drawdown comes primarily from the euro crisis in 2010. At that point, the basket was still being held following the 2008/2009 recession, and the riskier assets held were the most affected.

## Before 2001

The same rule, unchanged, from February 1979 onwards. Index histories standing in for necessary ETFs, plain world equity standing in for the core. Table below is from the start, to January 2001, starting with £10,000, after modelled transaction costs:

| | CAGR | Sharpe (over cash) | return / vol | max drawdown | £10,000 becomes |
|---|---|---|---|---|---|
| core + defensive | 14.8% | 0.32 | 0.89 | −37.6% | £208,800 |
| core + defensive + rebound | 17.9% | 0.45 | 0.97 | −38.1% | £373,000 |

(Average cash return in this period was ~10.2%, so Sharpes are lower. return/vol ignores the cash return)

The rebound basket still holds before 2001, as seen in the table. CAGR and Sharpe increases, at the slight cost of volatility and drawdown. The drawdown came from a false alarm re-entry.
